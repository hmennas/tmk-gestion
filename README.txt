TMK GESTION PWA
هذا مجلد تطبيق ويب قابل للتثبيت (PWA).
مهم: لا يمكن تثبيته كتطبيق كامل عند فتح index.html كملف محلي. يجب رفع جميع الملفات كما هي إلى استضافة HTTPS.
بعد النشر افتح رابط الموقع في Chrome على Android > قائمة ⋮ > تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
قبل الانتقال، صدّر نسخة JSON من بيانات التطبيق القديم. التخزين المحلي في رابط HTTPS سيكون منفصلاً عن تخزين file://؛ استعد النسخة الاحتياطية بعد التثبيت.
التطبيق يعمل دون اتصال للملفات الأساسية بعد أول زيارة، لكن ميزات الخط الخارجي قد تحتاج اتصالاً.
